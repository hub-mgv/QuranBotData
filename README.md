# QuranBotData

Data storage repository used by the main QuranBot project.

This repository contains:
- Quran reciters data
- Quran radio stations
- Azkar audio and images
- Quran metadata
- Additional assets used by QuranBot

## Live CDN Static Access
https://hub-mgv.github.io/QuranBotData/

## Main Project
https://github.com/mgv-hub/quranbot

## Repository Structure

- `/quran` Quran reciters JSON data
- `/audio` Audio files and azkar audio
- `/azkar-images` Azkar images
- `data_quran.json` Main Quran data source
- `adhkar.json` Main azkar data
- `azkar.json` Legacy azkar file kept for compatibility with older bot versions

## Purpose

This repository acts as a static content backend for QuranBot, providing public access to:
- Reciters
- Radio stations
- Quran metadata
- Audio resources
- Images
- Other runtime assets
